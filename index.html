Every9D-21M: Large-Scale Real-World 9D Canonicalization of Everyday Objects

Leonhard Sommer, Emil Akopyan, Adam Kortylewski

arXiv preprint, 2026

A dataset of 9D pose labels for 21.8M real-world images from 109K object-centric videos across 700 everyday categories, about two orders of magnitude larger than earlier real-world 9D pose benchmarks. Canonical poses are propagated from a small manually annotated reference set and verified from multiple views.

Category-Level 3D Correspondence in Camera Space via Morphable Object Priors

Leonhard Sommer, Artur Jesslen, Basavaraj Sunagad, Adam Kortylewski

ECCV 2026

Predicts 3D locations that stay consistent across all instances of a category from a single image. Introduces HouseCorr3D, a benchmark of 178k images over 50 household categories, and Morpheus, which learns morphable shape priors by disentangling canonical shape, deformation and pose.

Paper Code Dataset Project Page

C3PO: Canonicalization of 3D Pose from Partial Views with Generalizable Correspondence Features

Y. Chi, Leonhard Sommer, Olaf Dünkel, Dominik Muhle, Daniel Cremers, Christian Theobalt, Adam Kortylewski

3DV 2026

Canonicalizes objects of arbitrary categories from partial views. Each view is lifted to a feature point cloud with features that generalize to unseen categories, and a pairwise registration framework aligns the partial reconstructions into one global canonical frame.

Paper Code

Common3D: Self-Supervised Learning of 3D Morphable Models for Common Objects in Neural Feature Space

Leonhard Sommer, Olaf Dünkel, Christian Theobalt, Adam Kortylewski

CVPR 2025

Learns 3D morphable models of common objects from object-centric videos without any labels. Objects are a learned template mesh plus an image-conditioned deformation field, with appearance encoded as contrastively trained neural features, enabling zero-shot 3D pose estimation and semantic correspondence.

Paper Code Project Page

Unsupervised Learning of Category-Level 3D Pose from Object-Centric Videos

Leonhard Sommer, Artur Jesslen, Eddy Ilg, Adam Kortylewski

CVPR 2024

Learns category-level 3D pose only from casually captured object-centric videos. A multi-view alignment with a cyclic distance over coarse meshes and DINOv2 features finds canonical poses across videos, which then train a single-image model predicting dense correspondences to a template mesh.

Paper Code Dataset Project Page

SF2SE3: Clustering Scene Flow into SE(3)-Motions via Proposal and Selection

Leonhard Sommer, Philipp Schröppel, Thomas Brox

GCPR 2022

Segments a scene into rigidly moving objects from two consecutive stereo or RGB-D frames by repeatedly proposing SE(3) motions from sampled pixel sets and selecting the best ones under a maximum-coverage formulation. On par for scene flow and more accurate for segmentation and odometry than prior work.
